# VANITAS Sticker Atelier

تطبيق Android أصلي بواجهة عربية داكنة وأنيقة لإنشاء حزم ملصقات WhatsApp. يختار الصور من الجهاز، يحولها محليًا إلى WebP بقياس 512×512، ينشئ صورة الغلاف، ثم يسلّم الحزمة إلى WhatsApp أو WhatsApp Business عبر واجهة Android الرسمية للحزم وContentProvider للقراءة.

## التشغيل

1. افتح هذا المستودع في Android Studio (الإصدار يدعم Android Gradle Plugin 8.7.3 أو أحدث).
2. ثبّت Android SDK 35 وJDK 17 عند الطلب، ثم انتظر Gradle Sync.
3. شغّل التطبيق على هاتف Android عليه WhatsApp أو WhatsApp Business.
4. أدخل اسم الحزمة والناشر، اختر الصور، ثم اضغط «إضافة الحزمة إلى WhatsApp» وأكمل التأكيد داخل WhatsApp.

لا يحتاج التطبيق إلى صلاحية تخزين عامة؛ اختيار الصور يتم من منتقي النظام. الصور لا تغادر الجهاز. الحد الحالي 30 صورة لكل حزمة، ويجب أن تكون صور الملصقات مناسبة (شفافة/مقصوصة بحسب رغبتك)؛ التطبيق يضع الصورة داخل مساحة شفافة مربعة ولا يزيل الخلفية تلقائيًا.

## ملاحظات

- معرّف التطبيق وContentProvider authority متطابقان باستخدام `${applicationId}.stickerprovider`.
- واتساب يقرأ بيانات الحزم والملصقات من `StickerContentProvider`؛ لا تُرسل ملفات الصور مباشرة عبر Intent.
- يتطلب البناء اتصالًا بالإنترنت في المرة الأولى لتنزيل إضافات Gradle.
- إعدادات المتجر (الأيقونة النهائية، سياسة الخصوصية وروابط النشر، توقيع إصدار الإنتاج) تُضاف قبل النشر العام.
